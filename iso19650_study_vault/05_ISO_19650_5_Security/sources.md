## Rejected / link-only

- Full text of ISO 19650-5:2020: paywalled-metadata-only.
- OBP preview: fetch timed out.
- PAS 1192-5:2015, PAS 185, and PAS 1085: legacy (predecessor). Named by NPSA as material the ISO standard replaces or absorbs. Not used as current rules. [P5-S02]
- Guidance Part 1 (July 2019), section 3.3: outdated on this point. It tells the reader to keep using PAS 1192-5 until ISO 19650-5 is published. Part 5 was published in June 2020. [P5-S01]
- NHSScotland ISO 19650 Navigator is kept as P5-S08 only for the ST1–ST4 claim. It is not a reading source for the rest of this part. HEAD returned HTTP 200. The licence for a local copy was not established.
- BSI press page for the July 2020 publication: direct request returned HTTP 403, and the page was not used.

## Recommended reading order

1. P5-S01 (20 minutes).
2. P5-S02 (20 minutes).
3. P5-S03 (45 minutes).
4. P5-S04 (30 minutes). Read it against P5-S03 and do not assume the two documents use one name for the first step.
5. P5-S06, section 2.5, and P5-S07, the clause 9.2 paragraph (30 minutes).
6. P5-S05 (10 minutes), so you know where the UK framework sends you next.
